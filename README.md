### 🚀 Текущий проект

#### [youtube-to-viral-clips](https://github.com/damanrud/youtube-to-viral-clips)

Личный проект — пайплайн, который превращает длинные видео и стримы в короткие вертикальные клипы:

- 📥 Загружаешь большое видео или запись стрима
- 🧠 Система анализирует контент с помощью **Ollama** (локальная LLM)
- ✂️ Нарезает и монтирует лучшие моменты в TikTok-формат через **FFmpeg**
- 📤 Автоматически публикует готовые клипы на **YouTube**
